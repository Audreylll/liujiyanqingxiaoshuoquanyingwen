# 潮汐来信 · 六级词汇双语小说

直接双击 `index.html` 即可使用，无需安装依赖。

功能：

- 12 章连续原创言情悬疑故事，中英逐段对照
- 英文、中文、音标三项独立显示开关
- 英文朗读 / 英文加中文朗读，以及单段、单词朗读
- 每章自动汇总正文目标词、音标和中文释义
- 两种默写表导出：英译中、汉译英（浏览器打印窗口中另存为 PDF）
- 内置所附文档的 5523 条完整六级词库，支持搜索
- 阅读进度、收藏章节自动保存在浏览器本地
- 响应式布局与夜间模式

如原始词汇 Markdown 更新，可在 PowerShell 中运行：

```powershell
.\build-vocab.ps1
```
